# Portfolio Website — Sumit Kumar

This is a simple, responsive portfolio website for Sumit Kumar to showcase projects and contact details.

## How to use
- Replace `YOUR_USERNAME` and `YOUR_LINKEDIN` in `index.html` with your actual GitHub and LinkedIn links.
- Replace email `your-email@example.com` with your real email.

## Files
- `index.html` — main page
- `style.css` — styles
- `script.js` — small interactions

## Publish
You can publish this site with GitHub Pages (see instructions below).
